name: sharpen
description: "Make a task deeper, not bigger, then rewrite the prompt. Use for /sharpen."
---

Rewrite the prompt to make the task deeper, not bigger. In the rewritten prompt, ask for what a top practitioner would add within the original scope:

- The substantive work the original prompt leaves out.
- The primary evidence they would start from instead of a summary.
- The specific methods and tools they would use.
- An independent observation that would show whether the result is right.

For choices an experiment can settle, ask the agent to run the smallest prototype that distinguishes the options and recommend one based on what it observes. Leave product and preference choices an experiment cannot settle to the user.

Return only the rewritten prompt. Do not answer it, explain the rewrite, or add a preamble.
