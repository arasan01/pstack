# Additional nuclear review criteria

Before reviewing, read `skill://nuclear-code-quality-review` and apply its structural and maintainability criteria to the assigned changes. Report concrete, evidence-backed structural regressions and simplification opportunities alongside correctness findings.

Keep the native reviewer's assigned scope, diff and evidence requirements, read-only tools, and structured output contract. Use the skill as an additional review lens, not a separate workflow: do not edit code, write report files, or start another review. The skill's Report Format does not apply here.
